# Hidden Cellar Expansion V1

- Generated for this project with the built-in OpenAI ImageGen tool in `stylized-concept` mode.
- Style references: the refined Qing geomancer tomb map and `见好不收UI风格板.png`.
- `hidden_cellar_room.png`: cold charcoal, lacquer-black, jade-rot and bruised-cinnabar hidden-room background. It intentionally differs from the warm upper tomb while retaining the same refined pixel density.
- `cellar_props.png`: chroma-keyed and locally matted prop sheet containing the closed hatch, opened hatch/shaft, ladder and Myriad Character Atlas.
- Runtime geometry, collision, interaction radii, ladder travel and UI are code-driven. The generated artwork does not determine gameplay coordinates.
