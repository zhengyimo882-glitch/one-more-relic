# Mural Discovery UI v1

- `mural_discovery_chrome.png`
  - Generated with the built-in image generation tool for this project.
  - Environment reference: `TOMB_SCREENSHOTS/TOMB_B_corridor_mural_light.png`.
  - Final direction: a transparent, irregular Qing-tomb brick/plaster aperture with a roofed old-wood and aged-bronze inscription rail, restrained cinnabar cords, geomancy carving, verdigris, pigment dust and warm flashlight edging.
  - The oversized first-pass compass obstruction was removed; the final central opening and outer corners use real alpha transparency.
  - No generated text is used. All titles, descriptions, counters and input hints remain code-rendered for localization and accessibility.

The four mural paintings are existing project assets under `public/assets/tomb_murals/` and were not regenerated or composited into this chrome texture.
