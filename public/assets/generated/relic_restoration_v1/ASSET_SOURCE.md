# 文物修复样板资产来源

本目录为《见好不收》古玩店“文物清理与观察”样板玩法的正式运行时位图资源。资源通过 Codex 内置 ImageGen 生成，再由 `scripts/prepare-restoration-assets.ps1` 裁切、去背景、对齐并生成接触阴影。

## 生成模式

- 模式：Codex 内置 ImageGen
- 用途：2D 网页游戏正式透明 PNG，不是几何占位
- 统一方向：中式民俗微恐、旧木、黄铜、旧纸、铜绿、暖色侧上工作灯

## 主要提示词摘要

1. 祭祀钱净面：三视图（正、反、侧缘），不规则铸铜轮廓、方孔、缺口、厚度、八卦与残铭、铜绿和细划痕，透明背景。
2. 祭祀钱重污：保持三视图布局，叠加浮尘、墓泥、黑锈、铜绿粉和矿物硬壳，遮住约 70% 铸纹。
3. 祭祀钱损伤：保持布局，加入竹签新刮痕、亮铜擦伤、边缘沟槽和新鲜包浆剥落。
4. 线装册净面：四状态（封面、封底、书脊、展开内页），泛黄变形纸页、线装、卷边、虫蛀、水渍与折痕，透明背景。
5. 线装册重污：保持四状态布局，加入浮尘、烟灰、霉点、水位线和缝线积垢，遮住纸纤维与暗折痕。
6. 线装册损伤：保持布局，加入新鲜擦毛纤维、磨掉的淡印、短裂口、松线和局部刮擦。
7. 工具：软毛刷、竹签、干棉布三件独立透明游戏精灵，旧木与黄铜材质、暖色侧光。
8. 工作台组件：旧木与黑棕皮革修复垫、黄铜包角、折叠/展开记录本、黄铜工作灯，透明分层素材。

## 运行时层级

- `*_clean.png`：干净文物底图与证据细节层。
- `*_dirty.png`：连续擦除的污垢/锈蚀/霉斑覆盖层。
- `*_damaged.png`：错误工具与过度操作产生的可见损伤层。
- `*_shadow.png`：由文物透明轮廓派生的接触阴影层。
- `front/back/edge/spine/open`：正面、背面、侧缘、书脊、展开状态。

原始 ImageGen 输出保留在 Codex 生成目录中；项目内只保存经过运行时裁切和透明处理的正式资源。
