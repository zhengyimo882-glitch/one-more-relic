# Original Tomb Artifact Art

These PNGs were created specifically for *One More Relic / 见好不收* on
2026-08-11. They are project-bound generated artwork and do not replace or
overwrite any imported third-party asset pack.

## Runtime assets

- `geomancers_compass.png` — a square lacquered wood feng-shui luopan with a
  circular bronze plate, concentric calibration rings, bagua trigrams and a
  red-and-black needle. It intentionally contains no generated Chinese text.
- `bronze_mirror.png` — an upright excavated bronze mirror back with taotie,
  paired birds, cloud relief, verdigris and an integrated beast-foot stand.
- `burial_vessel.png` — a painted grey-clay funerary vessel with a bird finial,
  beast-loop handles, mountain/cloud bands and an abstract spirit procession.

All three masters were generated independently with the built-in image tool on
a flat magenta chroma-key field. The field was removed locally, the visible alpha
bounds were cropped, and the final runtime files were downsampled with Lanczos
filtering. Their original generated masters remain outside the repository.

Runtime filtering is linear. Placement uses a calibrated lower ground-contact
anchor rather than the original image-canvas center. Phaser graphics are retained
only for invisible shadows and interaction highlight outlines, not as artifact art.
