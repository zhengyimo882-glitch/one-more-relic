# Antique shop original art v2

These runtime PNGs were created for the local *One More Relic / 见好不收* prototype with OpenAI's built-in image generation tool on 2026-08-11. They are project artwork, not a third-party asset pack or an author-supplied license.

## Files

- `shop_interior_background.png` — complete 1280×720 hand-painted shop shell: aged walls, timber floor, built-in shelves, antiques, back door and lanterns.
- `shop_counter.png` — isolated low carved rosewood service counter, transparent background.
- `display_table.png` — isolated carved rosewood display table, transparent background.
- `counter_clutter.png` — isolated ledger, receipts, abacus, inkstone, brushes, seal case, cup and wrapped relic arrangement.
- `brass_tally.png` — isolated chipped brass inventory tally.
- `commission_tools.png` — isolated canvas satchel, route, rope, key, provisions and wooden torch arrangement.
- `shop_interior_background_source.png` — retained full-resolution generated background source.

## Prompt direction

All pieces use a fixed elevated top-down game view and a moody Chinese folk-horror palette. The environment prompt requested an old Chinese antique shop at night with organic hand-painted detail, open navigation space, no people, no counter and no UI. Prop prompts requested isolated handcrafted objects with natural wear, no readable writing and no simple geometric placeholder styling. Transparent props were generated against a solid magenta key and converted to alpha without altering the original generated source files outside this project folder.

The counter was regenerated after in-game review to use a long, low 4.5:1 silhouette with a shallow top plane so the shopkeeper remains visible behind it.
