# 《见好不收》网页 Demo 美术方向 v1

## 1. 视觉锚点

- 采用“精细像素 / 低分辨率手绘混合风格”。现有古玩店与主墓地图是构图、材质和明暗密度锚点。
- 画面保持中式民俗恐怖：旧木、土黑、暗铜、铜绿、朱砂、旧纸；避免明亮卡通、现代扁平、塑料手游和照片写实。
- 世界资产先在低分辨率画布完成，再以整数倍放大。角色、家具、器物在 100% 游戏尺寸下必须共享相近 texel density。

## 2. 1280×720 基准

| 项目 | 执行值 |
| --- | --- |
| 逻辑分辨率 | 1280×720 |
| 世界角色可见高度 | 主角 82px；老板 88px |
| 角色源帧 | 128×128；有效轮廓居中，脚底锚点 y=104px |
| 外轮廓 | 1px 源像素，最大 2px 等效宽度 |
| 角色缩放 | 1× 或 2×整数缩放；世界图使用 NEAREST 采样 |
| 物理碰撞 | 只覆盖脚部，宽 22px、高 14px，脚底前留 2px |
| 深度锚点 | 人物脚底 / 家具接地点的世界 Y；`depth = base + y / 1000` |
| 接地阴影 | 28×11px 方向性软边阴影，锚定脚底后上方 2px；不使用大圆影 |

- 古玩店：环境 Tint `#F0C184`，角色综合色乘数 0.93，暗部偏赭褐；局部灯光最高增加 12% 暖度。
- 墓穴：环境 Tint `#A6B0A4`，饱和度观感降低约 18%，暗部偏冷黑和铜绿；角色不得保持独立高亮。
- 地窖：环境 Tint `#86A8A4`，整体亮度比主墓再低 8%，湿石高光限制在低饱和冷青。
- 烛火：半径 120px 内向 `#D98545` 插值，最大局部权重 0.28。
- 材质统一不是全局滤镜：地窖、壁画和墓道分别重采样至目标密度，并限制局部锐度与高频对比。

## 4. 角色语言

- 主角识别锚点：乱短发、疲惫含胸、旧深青夹克、斜挎工具包、灰白内搭。
- 老板识别锚点：后梳灰发、长衫与旧马甲、左肩略低、双手克制收拢；压迫感来自身高微差与站位，不来自更高清的五官。
- 世界角色和头像共用发型、服装色块、脸部明暗方向。头像使用 192×192 方形构图，保留同一低分彩块与像素边缘。

## 5. 器物三层资产

每件核心器物必须通过 `artifactVisualManifest.ts` 同时登记：

1. 世界图：64×64 PNG，透明背景，NEAREST 采样；轮廓在 36–56px 范围。
2. 背包图：96×96 PNG，透明背景；保留裂痕、缺口、锈位等识别锚点。
3. 调查图：640×480 PNG，透明或旧纸中性底；主体占宽 56–72%，不得压住正文。

三层资源必须共享外轮廓、主色、裂痕、锈蚀、包浆、缺口与纹样位置。特写只允许增加材质信息。

## 6. UI 家族

- 统一为“黄铜线框 + 漆黑 / 旧纸双主题”。两种主题共用 8px 切角、24px 内边距、40px 标题栏和按钮状态。
- 主要面板使用正式九宫格纹理；Graphics 仅用于遮罩、调试、光照与过渡。
- 黑底：HUD、目标、交互和危险提示；旧纸：对话、调查、选择；结算采用黑底但保留黄铜框、器物剪影和同一排版层级。
- 同屏只保留一个主目标。次要帮助折叠；临时消息 3.2 秒内淡出；背包/调查打开时其他 HUD 降至 25% Alpha。

## 7. 排版与安全区

- 中文：Microsoft YaHei / PingFang SC；英文：Georgia（标题）与 Arial（正文）。
- 正文中文 18px、英文 17px、行高 1.48；标题 28px；标签 14px。
- 面板正文最大宽度 720px，左右 24px 内边距；底部操作安全区 72px。
- 以最长中文文案压测，所有正文启用自动换行；临时提示超过两行转为独立状态条，不缩小到 16px 以下。

## 8. 文件与回退

- 新资源只写入 `public/assets/art-v2/`，按 `characters/portraits/artifacts/{world,inventory,inspection}/ui/effects` 分类。
- 文件命名：`<subject>-v2-<role>.png`，全小写 kebab-case。
- 代码通过 Manifest 切换。回退时将 `ART_VERSION` 从 `v2` 改为 `legacy`，原 `public/assets/generated/` 不删除、不覆盖。
