# 《见好不收》网页 Demo 美术统一落地报告

日期：2026-08-25  
基线：`见好不收_网页Demo美术一致性审查报告_2026-08-25.docx` 与 GDD v0.2

## 落地结论

本轮已经把原先“写实角色 + 混合地图 + 纯文本物品 + 三套 UI”的主要断层，收束为一套低分辨率手绘像素语言：角色采用一致的轮廓、采样和脚底锚点；遗物建立世界 / 背包 / 检查三级资产；UI 统一为暗铜漆木与旧纸两类面板；古玩店使用暖琥珀光，墓室与暗室使用冷青环境光。

## 完成项

- 主角与老板：替换 4×4 方向图，统一 128 px 帧、最近邻采样、脚底锚点、环境色与椭圆软影；老板表情动作不再错误轮播方向列。
- 遗物：风水罗盘、万字图集、葬器、铜镜均提供 64×64 世界图、96×96 背包图、640×480 检查图；检查窗和背包不再依赖纯文字占位。
- UI：检查、背包、暗室发现、离墓结算和返店结算使用统一九宫格暗铜 / 旧纸面板；中英文字号、层级、间距与安全边距集中管理。
- 场景：暗室背景经过低频细节压缩与冷色分级；角色根据店铺 / 墓室状态切换暖冷环境色；墓室老板提示条由 920×172 缩减至 720×132。
- 空间：主角碰撞体改为 22×14 脚底区域；角色与老板使用脚底 Y 值计算深度；实测店内桌台阻挡后角色停留在合法通路。
- 满背包：图集发现窗的说明改为受控换行和最大行数，图像与状态区分栏，未出现越界。
- 回滚：旧资产未覆盖；移除新路径引用即可退回旧版。所有新文件集中在 `public/assets/art-v2/`。

## 剩余风险

- 当前店铺与主墓室大部分仍为单张合成背景，Y-depth 已统一，但柜台等建筑无法像拆层 tilemap 那样实现精细的前景遮挡；这是后续地图拆层工作的主要 P1。
- 角色图为首轮正式替换资产，四向动画目前偏克制；后续若增加攻击、拾取或受击动作，应沿用同一帧规格和调色板。
- Vite 仍提示主包约 1.56 MB，属于既有打包结构的性能提醒，不影响本轮功能和美术验收。
